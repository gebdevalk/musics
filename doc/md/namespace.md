# Namespaces

Every namespace under `src/`, by section, with its size in lines and its role. The program is used through **mu** (`musics.mu`, `lein mu`) and the **GUI** (`musics.gui.core`, mu's `gui`). 110 namespaces, 31,621 lines.

This page is generated by `python3 scripts/namespaces.py`: sizes and the list come from the source, and a role you edit here is kept (a new namespace gets the first sentence of its docstring). *unreached* marks a namespace nothing in `src/` requires, so only tests load it. The algorithms are not marked: a mu user loads one with `reqalgo`.
